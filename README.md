# 🥸 Who am I?

Play "Who am I" with your friends if you do not have any pen and paper.

It works without any server. Everyone enters the identities for each player on one phone and then
you can generate a QR Code for everyone to scan. They select their player name and will see everyone
elses identities. Theirs will be hidden from them.

## Development

```sh
gleam run -m lustre/dev start
```
